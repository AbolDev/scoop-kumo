# scoop-kumo

[Scoop](https://scoop.sh) bucket for [Kumo](https://github.com/AbolDev/kumo-client), a free VPN client
powered by sing-box and Xray.

```
scoop bucket add kumo https://github.com/AbolDev/scoop-kumo
scoop install kumo
```

Kumo asks for administrator rights when it starts: the tunnel needs them.

The manifest follows the releases of the main repository (`scoop update kumo`).
